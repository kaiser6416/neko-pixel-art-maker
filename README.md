# ねこドット絵メーカー

猫の写真を背景透過のドット絵（16×16 / 32×32 / 64×64）に変換するブラウザ完結の無料ツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや `npm install` は不要です。

1. 猫の写真をアップロード（ドラッグ＆ドロップ、またはタップして選択）
2. サイズ（16×16 / 32×32 / 64×64）を選択
3. 必要に応じて背景透過の強さを調整、またはスポイトで背景色を指定
4. 実寸 or 拡大サイズで透過PNGを保存

処理はすべて端末のブラウザ内（Canvas API）で完結し、画像はどこにも送信されません。

## 公開方法（例）

- GitHub Pages: リポジトリの Settings → Pages で `main` ブランチを指定するだけで公開できます。
- ローカル: `index.html` をダブルクリックして直接開いても動作します。

## 背景透過の仕組み

画像の外周から同系色をたどって塗りつぶす方式（マジックワンド的な処理）です。無地・単色背景の写真で最もきれいに抜けます。複雑な背景の場合はスポイト機能で背景色を指定するか、透過の強さを調整してください。
